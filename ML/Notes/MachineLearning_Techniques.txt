DAY 1: WHAT IS MACHINE LEARNING?

Machine Learning is about building programs that learn patterns from data instead of being explicitly programmed with rules.
​
A typical ML system :  input data → learning algorithm → model → predictions/decisions.
How ML differs from traditional programming
Traditional :  programmer writes rules + data → outputs.
ML : programmer supplies data + outputs (labels) → algorithm learns the rules (model).
​
Useful when rules are too complex or unknown (e.g., image recognition, speech).
Typical ML workflow (high-level mental model)
Data collection.
Data cleaning and preprocessing.
Feature selection/engineering.
Model selection (choose algorithm).
Training (fit model to training data).
Evaluation (check performance on unseen data).
Deployment (use model in real system).
Email spam detection.
Recommendation systems (YouTube, Netflix).
Medical diagnosis and fraud detection.
​
ML = learning from data, not hard-coded logic.
Success depends strongly on data quality, not just algorithms.
Think in terms of “input → model → output” rather than “if–else rules”.

DAY 2: AI VS ML VS DL
​
Artificial Intelligence (AI)
Broad field : any technique that enables computers to mimic human intelligence (reasoning, planning, learning, perception).
​
Includes rule-based systems, search, planning, expert systems, ML, etc.

(ML) -> Subset of AI focused specifically on learning from data.
 	Model discovers patterns and relationships automatically.
(DL) -> Subset of ML using neural networks with many layers (deep architectures).
Especially good for images, audio, text, where raw features are complex.

DL ⊂ ML ⊂ AI.

Not every AI system uses ML; not every ML system uses deep learning.

When to use what :
Rule-based AI: clear rules, low complexity.
ML : structured/tabular data, moderate complexity.
DL : large amounts of data (images, audio, text) + higher computation budget.

Don’t call everything “AI”; be precise: ML vs DL vs rule-based.
Deep Learning doesn’t replace ML; it’s a powerful specialization.

DAY 3: TYPES OF MACHINE LEARNING
​
1. Supervised Learning
Definition: model learns from labeled data (input X, known output y).
Goal: learn mapping
f : X → y
f : X → y to predict y for new X.
Regression : predict a continuous value (house price, salary).
Classification : predict a discrete category (spam/ham, disease/no disease).
​

2. UNSUPERVISED LEARNING
Definition : model learns structure in unlabeled data (only X, no y).
Goals:
Clustering (group similar points).
Dimensionality reduction (compress features).
Examples: customer segmentation, grouping documents.

3. SEMI-SUPERVISED LEARNING
Mix of small labeled data + large unlabeled data.
Useful when labeling is expensive but raw data is abundant.

4. REINFORCEMENT LEARNING
Agent interacts with environment, gets rewards, and learns a policy to maximize cumulative reward.
​
Examples: game-playing agents, robotics, recommendation strategy.

Supervised: “I have answers; learn to mimic them.”
Unsupervised: “No answers; find patterns.”
RL: “Learn by trial-and-error with rewards.”

Day 31 : Power Transformer

Box-Cox transformer

xi^k = {	(xi-1)/k, if(k != 0)
 		ln(xi), 	if(k = 0)
}

The exponent here is a variable called lambda (A) that
varies over the range of -5 to 5, and in the process of
searching, we examine all values of A. Finally, we choose
the optimal value (resulting in the best approximation to a
normal distribution) for your variable.

limitation : xi > 0

thats why we need yeo johnson

yeo johnson transformer

xi^k = {
 	case 1 : if(k != 0 && xi >= 0)
 	case 2 : if(k == 0 && xi >= 0)
 	case 3 : if(k != 2 && xi < 0)
 	case 4 : if(k == 2 && xi < 0)
}

This transformation is somewhat of an adjustment to the
Box-Cox transformation, by which we can apply it to
negative numbers.

Complete Case Analysis (CCA):
 	CCA also called as "list-wise deletion" of cases, consist in discarding  observation where  values  in any  of the variable is missing.
 	Complete Case analysis means literally analyzing only those observations for which there is information in all of the variables in the dataset.

Assumptions for CCA :
 	1. Data is missing completely Random(MCAR) -> Missing Completely At Random
 	Advantages : 	1. Easy to implement as no data manipulation is required.
 					2. Preserves variable distribution (if data is MCAR , then the distribution of the variables of the reduced dataset should match the distribution in the original dataset).
 	Disadvantages :	1. It can exclude a large fraction of the original dataset (if missing data is abundant)
 					2. Excluded Observations could be informative for the analysis (if data is not missing at random)
 					3. When using our models in production, the model will not know how to handle missing data.

When to use CCA?
 	MCAR, < 5% missing data

Imputations :
 	1. Mean and median Imputation : when MCAR and <5% missing data
 	2. Arbitrary Value Imputation : filled with any value (NA -> missing) : when data is not missing a random
 	3. End of Distribution Imputation : instead of arbitrary value use end of distribution values. IQR proximity rule
 	4. for categorical data if data id MCAR or <5% missing use mode (most frequent)
 	5. Missing Category Imputation : make different category named (missing)

Day 40 : Multivariate Imputation by Chained Equations for Missing Value | MICE Algorithm | Iterative Imputer

MICE -> Multivariate Imputation by Chained Equations

Assumptions :
 	1. MCAR : Missing Completely At Random
 	2. MAR : Missing At Random
 	3. MNAR : Missing Not At Random

More Accurate but Slow

STEPS :
 	1. Fill all the NAN values with mean of respective cols
 	2. Remove all col1 missing values
 	3. Predict the missing values of col1 using other cols
 	4. Remove all col2 missing values
 	5. Predict the missing values of col2 using other cols
 	6. Remove all col3 missing values
 	7. Predict the missing values of col3 using other cols

do it until we get difference almost or near to zero

Day 47, 48 : (PCA) | Part 1 | Geometric Intuition

PCA is unsupervised learning problem.
Complex technique
Reduces Curse of Dimensionality
Faster Executes the algorithm
great for visualization


Feature Selection : Checks Data Spread (where it is more) : Data should spread in wide range, use variance or scatterplot to checkout

Feature Extraction : It is like combining two features to derive another meaningful feature helpful in improving model at low features.

PCA makes new set of features by feature selection or feature extraction and chooses the subset which is more important in decision making.

Remember Rotation of Axis to make Principal components and choosing more suitable component where again the variance is more than other principal components.
Number of PC <= Number of original features in original Data

Var(x) = Summation( Sq(xi - mean(x))) / n

Stdev(x) = Sqrt(Var(x))


after rotation the variance of all the projections given as :
	Var(x, U) = (Summation(sq(Ut.xi - Ut.xm)))/n

Covariance and Covariance matrix : 
 - covariance gives the relation how x and y are changing with each other -> summatioin(xi*yi)/n
  	x1	[ Cov(x1, x1)		Cov(x1, x2) ]         		[ Var(x1)	 Cov(x1, x2) 	]
 	x2	[ Cov(x2, x1)		Cov(x2, x2) ]            ->       	[ Cov(x2, x1)	 Var(x2)		]	-> Covariance Matrix
			x1				x2

Note : 	Cov(a, b) = Cov(b, a)
		Cov(a, a) = Var(a)

Linear Transformation, Eigen Vector and Eigen Values : 
Geogebra : tool to visualize transformations

The vectors which do not change its direction after applying transformation are called as Eigen vectors and the amount by which their magnitude grows or shrink are called Eigen Values.

A.v = k.v  ....( v = eigen vector, A = transformation, k = Eigen value)
